# 02 · A 股的游戏规则

> 时间预算 3 小时。这一章几乎没有代码，但它决定了你的回测是不是在"打一款不存在的游戏"。

## 为什么必须先学规则

你可以写出完美的代码，跑出漂亮的曲线，然后发现**这个策略在 A 股根本没法执行**：

- 你设计成"当天买当天卖" → T+1 不允许
- 你假设能买 37 股 → 只能 100 股整数倍
- 你没考虑涨停 → 想买的票开盘就封板，买不进去
- 你用了不复权价格 → 分红那天凭空亏 30%，策略把好公司卖了

**回测的第一原则：先确认你的策略在真实市场里能被执行。**

## 一、交易时间

| 时段 | 时间 | 能做什么 |
|---|---|---|
| 集合竞价（开盘） | 9:15–9:25 | 挂单，9:25 统一撮合出开盘价 |
| 连续竞价（上午） | 9:30–11:30 | 正常买卖 |
| 连续竞价（下午） | 13:00–14:57 | 正常买卖 |
| 集合竞价（收盘） | 14:57–15:00 | 挂单，15:00 出收盘价 |

**对回测的意义**：你白天要上班，只能 9:25 前挂单或者收盘后决策。
所以这个教程所有策略都是「**今天收盘算信号，明天执行**」—— 这也是 `backtest.py` 里那句 `shift(1)` 的现实依据。

如果你写"当天收盘价买入"，在实盘里意味着你必须在 14:57 前就知道收盘价，做不到。

## 二、T+1：今天买的，明天才能卖

这是 A 股和美股最大的区别。美股 T+0，当天可以反复买卖；A 股不行。

**影响**：

- 任何"日内止损"策略在 A 股个股上**直接失效**（ETF 和可转债是 T+0）
- 隔夜跳空风险无法规避 —— 今天暴跌 8%，你只能看着，明天才能跑
- 回测里如果出现"当天买入、当天卖出"，就是 bug

## 三、涨跌停：想买买不到，想卖卖不掉

| 板块 | 涨跌幅限制 |
|---|---|
| 主板（600/000/601/002） | ±10% |
| 创业板（300）、科创板（688） | ±20% |
| ST / *ST | ±5% |
| 北交所 | ±30% |
| 新股上市首日 | 主板 44%，创业板/科创板无限制 |

**这是回测里最容易被忽略、也最致命的一条。**

真实情况是：一只票涨停了，全天封死，你的买单排在几百万手后面，**根本成交不了**。
如果回测里你"在涨停价买入了"，第二天的收益就白捡了 —— 这叫**涨停板偏差**。

正确的处理方式：

```python
# 简化版：涨停当天不买入，跌停当天不卖出
limit_up = pct_chg >= 9.8        # 主板近似
limit_down = pct_chg <= -9.8

can_buy = ~limit_up.shift(1)     # 昨天没涨停，今天才买得进
can_sell = ~limit_down.shift(1)
```

本教程的策略是日频、隔日执行，受这个影响较小，但你必须知道它的存在。
**做打板、做事件驱动策略的人，这一段值一条命。**

## 四、交易成本：算清楚再谈收益

| 费用 | 费率 | 收取方向 | 说明 |
|---|---|---|---|
| 佣金 | 万 2.5（0.025%） | 买 + 卖 | 券商收，最低 5 元 |
| 印花税 | 千 0.5（0.05%） | **仅卖出** | 国家收，2023-08 从千 1 减半 |
| 过户费 | 万 0.1 | 买 + 卖 | 沪市收，深市免（2022 年后统一） |
| 滑点 | 0.05%~0.3% | 买 + 卖 | 你的成交价和理想价的差距 |

**一次完整的买卖，成本大约 0.15%~0.2%。**

听起来不多？算笔账：假设你每周换仓一次，一年 50 次完整买卖，成本 50 × 0.2% = **10%**。
**你的策略必须先赚 10% 才能保本。** 这就是为什么高频策略对散户几乎必死。

## 五、复权：新手第一杀手

### 先看一个真实场景

贵州茅台 2023 年每股分红 25.9 元，除权日股价从 1700 掉到 1674。
如果你用**不复权**价格算收益，这一天就是 **-1.5%**，看起来像跌了。

但你没亏钱 —— 你手里多了现金。**账面上是"跌"，实际是"分红"。**

送股更夸张：10 送 10，股价直接腰斩 50%。不复权数据看起来像暴跌，实际你的股数翻倍，一分没少。

### 三种复权方式

| 方式 | 处理 | 适合场景 |
|---|---|---|
| **不复权**（none） | 原始价格，分红除权日会跳空 | 看真实成交价、算涨跌停、算一手要多少钱 |
| **前复权**（qfq） | 把历史价格按复权因子往下调，**最新价 = 真实价** | ✅ **回测算收益，默认用这个** |
| **后复权**（hfq） | 把未来价格往上调，**最早的价格 = 真实价** | 长期持有收益分析、避免前复权"历史价格会变"的问题 |

### 前复权的一个隐藏坑

前复权的价格是**动态的**：每次分红，历史上所有价格都会被重新调整。

意思是：**你今天下载的数据，和三个月前下载的同一段历史，数值不一样。**

这在研究上会带来麻烦 —— 你上周回测年化 18%，这周重跑变成 17.5%，因为期间分红了。

**解法**：要么用后复权做研究（历史数值固定），要么把复权因子单独存下来。
本教程默认用前复权，因为它算出来的收益率最直观。

### 代码里怎么用

```python
# src/data.py 里已经封装好，第三个参数就是复权方式
prices = load_daily("600519", "2020-01-01", "2024-12-31", adjust="qfq")
```

## 六、停牌、退市、ST

- **停牌**：数据里会缺日期。回测时 `pct_change()` 会把停牌前后的收益连起来算，看起来像"某天暴涨"，其实是两天的累计。**严谨的做法是停牌期间标记为不可交易。**
- **退市**：你的股票池如果只包含"现在还活着"的票，就是**幸存者偏差**（第 6 章详讲）。
- **ST**：涨跌停 ±5%，且很多机构不能买。如果你的策略选到了 ST 股，说明因子有问题。

## 七、最小交易单位与资金门槛

- 买入必须是 **100 股（1 手）的整数倍**
- 卖出可以不足 100 股（比如送股产生的零股）

这意味着：茅台 1700 元/股，一手要 17 万。**你 10 万的账户根本买不了一手。**

回测里必须处理：

```python
shares = int(cash / price / 100) * 100     # 向下取整到 100 股
```

不处理的话，回测会假设你能买 58.8 股 —— 一个不存在的世界。

## 八、其他会影响回测的细节

| 规则 | 影响 |
|---|---|
| 新股上市首日不设涨跌幅（部分板块） | 打新策略要单独处理 |
| 分红要交红利税（持股期限不同税率不同） | 长期持有策略的实际收益会低一点 |
| 融资融券有标的限制和利息 | 做空策略成本约年化 8% |
| 大宗交易折价 | 大资金建仓的实际成本高于市价 |
| 指数成分股每半年调整 | 指数增强策略必须用历史成分股，不能用今天的成分股 |

最后一条特别重要：**用今天的沪深 300 成分股回测过去 5 年，是典型的未来函数。**
因为能进今天成分股的，都是过去几年表现好的公司。
