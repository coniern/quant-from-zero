## 二、策略逻辑

双均线是最古典的择时策略：

- 快线（5 日均线）上穿慢线（20 日均线）→ **金叉，满仓**
- 快线下穿慢线 → **死叉，清仓**

经济学解释是"趋势延续"：短期资金动向领先长期共识，快慢线的交叉
意味着"短期共识和长期共识发生了切换"。

代码只有三行核心：

```python
ma_fast = close.rolling(5).mean()
ma_slow = close.rolling(20).mean()
signal  = (ma_fast > ma_slow).astype(float)   # 1 = 满仓，0 = 空仓
```

**注意这个约定的含义**：`signal` 是"当天收盘后你做出的决策"，
代表"从明天开始持有"。它不能直接乘当天的收益 —— 那是作弊（第 6 章）。

## 三、回测引擎逐行拆解

`src/backtest.py` 的 `run_backtest()`，核心就五行：

```python
ret  = close.pct_change()                    # 每天的收益率
pos  = signal.shift(1)                       # ★ 信号延迟一天生效
turnover = pos.diff().abs()                  # 换了多少仓
cost = turnover * (佣金+滑点) + 卖出量 × 印花税
strat_ret = pos * ret - cost                 # 策略每天赚多少
```

### 为什么 `shift(1)` 是全文件最重要的一行

你今天 15:00 收盘后才知道"金叉了"。钱最早明天开盘才能进去。
所以今天的仓位 = **昨天的信号**：`pos_t = signal_{t-1}`。

不 shift 会怎样？`examples/06_pitfalls.py` 实测：

| 写法 | 年化 | 夏普 |
|---|---|---|
| ✅ 诚实（shift 1 天） | 6.31% | 0.29 |
| ❌ 作弊（当天信号当天用） | **18.45%** | 0.75 |
| ❌ 先知（提前知道涨跌） | **464.77%** | 7.89 |

**少写一个 `shift(1)`，年化凭空多 12 个点。** 你以后看到"年化 50%+"的回测，
第一反应应该是：查它的信号有没有 shift。

### 成本是怎么算的

```python
turnover = pos.diff().abs()                  # 仓位变化量
sell     = (-pos.diff()).clip(lower=0)       # 仓位变小 = 卖出
cost = turnover * (0.00025 + 0.001) + sell * 0.0005
```

- 佣金万 2.5：买和卖都收
- 滑点 0.1%：你的成交价永远比理想价差一点
- 印花税千 0.5：只在卖出收

36 笔交易，成本吃掉了大约 2~3 个点的年化 —— **双均线这种换手率，成本是真实存在的敌人。**

## 四、`extract_trades()`：把仓位还原成交易

光看净值曲线不够，`trades` 表告诉你交易的"体质"：

| 开仓日 | 平仓日 | 收益率 | 持有天数 |
|---|---|---|---|
| 2020-02-04 | 2020-03-12 | -3.2% | 37 |
| 2020-04-01 | 2020-07-16 | +21.4% | 106 |
| ... | ... | ... | ... |

配合 `trade_stats()` 看四个数字：

- **交易次数**：36 次。频率越高，成本越疼，过拟合风险越大
- **交易胜率**：双均线通常 25%~40%（趋势策略低胜率是正常的）
- **盈亏比**：趋势策略靠"赢大亏小"活着，盈亏比 > 2 才有肉
- **平均持有天数**：持有 20 天的策略，你至少要能忍受 20 天的浮亏

## 五、结果解读：为什么跑不赢躺平？

回看净值曲线（`output/01_equity.png`），答案藏在 2020-2021：

1. **2020 年 2-3 月**：疫情暴跌，双均线躲过了大半 → 少亏，好
2. **2020 年 4 月-2021 年 2 月**：茅台暴涨，但途中每次小回调都会"死叉"把你甩下车，
   再金叉时价格已经高了 → **反复追高买入，少赚**
3. **2021-2024 震荡下跌**：反复金叉死叉，每次都是小亏 → **被磨损**

这就是择时策略的宿命：
**趋势行情里它赚"延续"的钱，震荡行情里它交"磨损"的税。**
5/20 双均线在茅台过去五年是"少赚 + 被磨损"，最终跑输躺平 30 个点。

**那择时还有什么意义？** 看两个东西：

- 回撤：-42.63% vs 躺平的 -51.30%（浅了一些，但没那么神）
- **换标的再看**：`examples/03_compare_strategies.py` 在沪深300、创业板指上重跑。
  你会看到：同一个策略，换个标的结论就变。**单一回测的结论是不可信的，这是本章真正的知识点。**

## 六、参数扫描：别调参，要检验稳健性

顺手把所有 (fast, slow) 组合跑一遍（`06_pitfalls.py` 里有完整代码）：

```
fast  slow  全样本年化  全样本夏普
  3    60      10.1%      0.452   ← 样本内最优
 20    60       9.2%      0.426
 10    60       8.9%      0.409
 ...
```

新手看到 MA3/MA60 最优，会直接用它。正确的做法是**把时间切开**：

- 用 2020-2022 选参数 → 选出 MA10/MA20（训练夏普 1.01）
- 拿到 2023-2024 检验 → **夏普 -2.30，年化 -26.45%**

**训练集和测试集的落差，就是过拟合的程度。**
落差不大的参数区域（比如整个 slow=60 那一排都不差）才叫"稳健"，
孤零零一个尖峰叫"运气"。
