# 00 · 学习地图

> 先看这一页，再决定从哪开始。不要跳着看，这个顺序是有原因的。

## 这个教程和别的不一样在哪

市面上量化教程的通病是：**讲完概念就丢一堆代码，代码你还跑不起来。**

这个仓库反过来：

1. **所有代码都能跑**。`pip install pandas matplotlib` 装完两个包就能跑，不需要注册任何平台、不需要 token、不需要 300MB 的依赖树。
2. **一个引擎贯穿到底**。不教你用三个不同平台各写一遍策略，而是自己写 60 行回测引擎，让你知道"回测到底在算什么"。
3. **专讲坑**。第 6 章整章在讲回测怎么骗人 —— 这一章比前面所有章加起来都值钱。
4. **有检查点**。每章末尾有自测题，答不出来就别往下走，往下走也是白走。

## 三条学习原则

**第一，先跑通，再理解。**
每章的代码先原样跑一遍，看输出，再回头读注释。**看不懂的代码跑一遍就懂一半了，看懂但跑不起来的代码等于没学。**

**第二，改坏它。**
跑通之后立刻做一件事：把参数改掉、把 `shift(1)` 删掉、把手续费设成 0，看结果怎么变。**你对一个系统的理解程度，等于你知道怎么弄坏它。**

**第三，用自己的话讲一遍。**
每章末尾的自测题，要求你**不看笔记**说清楚。说不清楚就是没懂，回去再看。能讲给别人听，才是真的会了。

## 怎么运行

```bash
# 1. 装依赖（只有两个，秒装完）
pip install -r requirements.txt

# 2. 跑第一个例子
python examples/01_hello_backtest.py

# 3. 看到 output/01_equity.png 就成功了
```

## 一个提醒

这个教程教的是**日频、股票、单市场**的量化。它不覆盖：

- 高频/做市（需要 tick 数据、毫秒级撮合、C++）
- 期权/期货的希腊字母与波动率曲面
- 机器学习因子挖掘（第 7 章打了基础，但那是另一个 100 小时的话题）

**先在一个领域扎到底，比什么都碰一遍强。** 日频股票策略是入门性价比最高的选择：数据免费、逻辑直观、面试也最常问。
