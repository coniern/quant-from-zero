# 04 · 收益与风险：把数字算明白

> 时间预算 6 小时。这一章的目标：**每个指标你都能在纸上算出来。**

## 为什么必须手算

`quantstats.show(returns)` 一行就能出 30 个指标。那为什么还要手算？

因为**面试和实盘都会问你"这个数字是怎么来的"**：

- "夏普 1.8，无风险利率取的多少？"（取 2% 还是 3%？日频还是年频？）
- "最大回撤 -35%，是从哪天到哪天？"（区间不同，数字完全不同）
- "年化收益是几何还是算术？"（差 2 个点，募资材料里不能乱写）

指标不难，难的是**知道每个数字的适用条件**。跑一遍 `examples/02_metrics.py`，
里面的手算和代码是逐项对过的，对不上就说明有理解错误。

## 一、从价格到收益率

一切从一个变换开始：

```
日收益率 r_t = (P_t - P_{t-1}) / P_{t-1}
```

```python
rets = close.pct_change().dropna()
```

两个必须注意的点：

1. **第一个值是 NaN**，必须 dropna，否则所有统计都被污染
2. **对数收益 vs 简单收益**：`log(P_t/P_{t-1})`。
   对数收益可以直接相加、截面可加性好，机构研究常用；
   但它不能直接对应用户的实际盈亏。本教程统一用简单收益，
   你只需要知道两者的区别（短周期差异可忽略）。

## 二、收益类指标

### 累计收益

```
累计收益 = Π(1+r_t) - 1
```

**是乘，不是加。** 茅台 2020-2024 累计 +65.88%，不是日收益之和。

### 年化收益（CAGR）

```
年化 = (1 + 累计收益)^(252/天数) - 1
```

茅台：65.88% 摊到 1212 个交易日 → 年化 **11.11%**。

三个细节：

1. **必须用几何平均**。先跌 50% 再涨 50%，算术平均是 0%，实际亏 25%。
2. 分母是**交易日数**不是自然日（一年约 242~244 个交易日，业界习惯用 252）
3. 亏损到本金归零时年化无意义（分母 ≤ 0）

## 三、风险类指标

### 年化波动率

```
年化波动 = std(r) × √252
```

茅台日波动约 2.12% → 年化 **33.68%**。

**为什么乘 √252？**
方差随时间线性增长（独立同分布假设），标准差是方差的平方根，所以随 √时间 增长。
写成代码就是 `rets.std() * np.sqrt(252)`。这是面试高频题。

### 最大回撤

```
回撤_t = 净值_t / max(净值_0..t) - 1
最大回撤 = min(回撤_t)
```

茅台 2020-2024 最大回撤 **-51.30%**。

注意三件事：

1. **回撤永远 ≤ 0**，写 -51.30% 而不是 51.30%（写错会显得不专业）
2. 回撤是"从最高点到之后最低点"，不是"年末比年初跌多少"
3. 比"多深"更重要的是**修复时间** —— 茅台 2021 年 2 月的高点，到 2024 年底还没修复
   （`max_drawdown_detail()` 会把峰值日、谷底日、修复天数都算出来）

**为什么回撤比收益重要？** 因为它决定了你"能不能拿得住"。
-10% 的浮亏是正常波动；-50% 的浮亏，90% 的人会割在底部。
**回撤决定策略的可用性，收益决定策略的价值。**

## 四、风险调整后收益

### 夏普比率

```
夏普 = (mean(r) - rf/252) / std(r) × √252
```

茅台：0.421。双均线策略：0.29。

- rf 用年化无风险利率（本教程取 2%）除以 252 转成日频
- **含义：每承担 1 单位波动，换来多少超额收益**
- 经验标尺：<0.5 不值得看；0.5~1 一般；1~2 不错；>2 先怀疑作弊（见第 6 章）

### 卡玛比率

```
卡玛 = 年化收益 / |最大回撤|
```

茅台：11.11 / 51.30 ≈ 0.22。

比夏普更贴近真实体验：**夏普管的是"每天的颠簸"，卡玛管的是"最惨时亏多少"。**
做趋势策略的人更看卡玛，因为趋势策略的日波动不大、但回撤可以很深。

### 胜率与盈亏比

```
胜率 = 盈利次数 / 总次数
盈亏比 = 平均盈利 / |平均亏损|
期望收益 = 胜率 × 平均盈利 - (1-胜率) × |平均亏损|
```

**两个反直觉的事实：**

1. **高胜率 ≠ 赚钱**。胜率 90%、盈亏比 1:20 的策略（比如卖期权），
   期望是正的，但一次黑天鹅就清零。
2. **低胜率也能赚大钱**。胜率 30%、盈亏比 3:1 的趋势策略，期望是正的，
   但你要能忍受连续 7 次止损 —— 这就是为什么交易心理如此重要。

## 五、和基准比：Alpha、Beta、信息比率

单看绝对收益没有意义 —— 2020 年闭着眼睛买都赚，2022 年怎么做都难。

### Beta（β）

把策略日收益对基准日收益做线性回归：

```
r_strategy = α + β × r_benchmark + ε
```

β = **跟大盘同涨同跌的程度**。β=1 完全同步，β=0.5 只有一半的波动。

茅台双均线策略 β=0.485 —— 因为它一半时间空仓，只吃到了半个市场的波动。

### Alpha（α）

回归的截距，年化后是**扣掉大盘影响后的超额收益**。

**这才是策略本身的能力。** 年化 20% 但 β=2（两倍杠杆风格），
在牛市里毫无含金量；年化 8% 但 β=0.2、α=6%，才是真本事。

### 信息比率（IR）

```
IR = mean(策略 - 基准) / std(策略 - 基准) × √252
```

和夏普的区别：**夏普比"无风险利率"，IR 比"基准"**。
做指数增强、相对收益考核的产品，IR 是核心指标（>0.5 算不错，>1 很强）。

## 六、`src/metrics.py` 的使用约定

```python
from src.metrics import summary, format_summary

s = summary(strategy_returns, benchmark_returns)
print(format_summary(s))
```

所有函数的**输入都是日收益率序列**（不是价格、不是净值），
只有 `max_drawdown` 接受净值。这个约定在 docstring 里都写了。

实现里的三个"坑位"提示（都是真实世界会遇到的）：

- `std(ddof=1)`：样本标准差（除以 n-1），和 Excel 的 STDEV 一致
- 对齐：算 Alpha/Beta 前 `join="inner"`，只保留两边都有的日期
- 年化 Alpha 用截距×252，Beta 不年化（Beta 没有时间单位）
