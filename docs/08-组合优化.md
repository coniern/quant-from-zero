# 08 · 组合优化：钱怎么分

> 时间预算 5 小时。对应代码：`src/portfolio.py` + `examples/05_portfolio.py`

## 一、被低估的问题

多数人把 100% 的精力花在"选哪只票"，0% 花在"每只买多少"。

但组合理论早就证明了：**同样的持仓，不同的权重，风险可以差一倍。**
而且"怎么分"比"选什么"更容易量化、更容易控制。

本章四种方案，全部只用 numpy 实现，不依赖 scipy：

| 方案 | 一句话 | 需要估计什么 |
|---|---|---|
| 等权 | 每只 1/N | 什么都不用 |
| 逆波动率 | 波动小的多配 | 各自波动 |
| 最小方差 | 让组合波动最小 | 完整协方差矩阵 |
| 风险平价 | 每只票风险贡献相等 | 完整协方差矩阵 |

注意最后一列 —— **越往下的方案，需要估计的量越多**。
记住这条线索，它会解释所有实验结果。

## 二、先看实测结果

`examples/05_portfolio.py`（10 只票，2022-2024，真实数据）：

| 方案 | 年化收益 | 年化波动 | 最大回撤 | 夏普 |
|---|---|---|---|---|
| 等权 | 3.6% | 24.5% | -36.9% | 0.19 |
| 逆波动率 | 4.4% | 23.4% | -35.2% | 0.21 |
| 最小方差 | 9.8% | **18.6%** | **-22.2%** | **0.49** |
| 风险平价 | 6.0% | 22.2% | -33.0% | 0.28 |

权重明细里藏着真正的知识点：

```
最小方差    长江电力 46.5%、茅台 18.8%，三只票权重为 0
风险平价    长江电力 21.9%，其余 7.5%~10.3%
```

## 三、逐个拆解

### 1. 等权：不要小看它

```
w_i = 1/N
```

DeMiguel 等人 2009 年的著名论文对比了 14 种优化模型：
**样本外，等权经常打败所有复杂模型。**

原因不是等权聪明，是**优化器蠢** —— 它依赖"估计准确的协方差矩阵"，
而估计误差会被优化器放大成极端权重。你估错了两只票的相关性，
优化器可能给出 -30% 的权重。

**量化里反复出现的主题：少一个要估计的量，就少一份误差。**

### 2. 逆波动率：够用的朴素

```
w_i ∝ 1/σ_i
```

只用对角线信息（各自的波动），不估相关性。实务里非常常用，
因为它**几乎不会给出离谱的权重**。

### 3. 最小方差：闭式解长什么样

目标 `min w'Σw`，约束 `Σw = 1`。拉格朗日求解：

```
w ∝ Σ⁻¹ · 1        （一行矩阵运算）
```

这就是"学线性代数有什么用"的答案。长仓约束下严格解需要数值优化，
本教程用"截断负权重再归一化"近似，效果足够好。

**看实测权重**：长江电力 46.5%，三只票为 0 —— 它找到了真正"波动小且与其他票相关性低"的资产。
这是它的本职工作。但注意两个隐患：

- 权重极度集中 → 单票暴雷的伤害被放大
- 这次它年化收益最高（9.8%）**纯属行情巧合**：2022-2024 恰好防御股跑赢。
  换个牛市样本，它大概率垫底。

### 4. 风险平价：让风险"民主"

**定义**：每只票对组合总风险的贡献相等。

风险贡献怎么算：

```
组合波动 σ_p = √(w'Σw)
边际风险贡献 MRC_i = (Σw)_i / σ_p      （多买一单位 w_i，组合波动增加多少）
风险贡献 RC_i = w_i × MRC_i            （归一化后总和 = 100%）
```

`risk_contribution()` 就是这个公式，跑完可以自己验证：
实测每只票的风险贡献**精确等于 10.0%**（10 只票各 1/N）。

算法是不动点迭代：

```
目标条件：w_i × (Σw)_i = 预算_i
不动点：  w_i = 预算_i / (Σw)_i
循环：    用当前 w 算 (Σw) → 更新 w → 归一化 → 重复
```

跑 1000 轮，收敛判据是权重变化 < 1e-12。你可以在代码里把
`risk_contribution(weights, rets)` 打印出来亲眼看它收敛到 10%。

**为什么机构爱风险平价？** 因为它控制的是"最坏情况的集中度"：
任何一只票崩了，对组合的伤害都被限制在 1/N 附近。
桥水的全天候策略就是这个思想的规模化版本。

## 四、再平衡：被忽略的隐形开关

`portfolio_returns(weights, rets, rebalance="ME")` 里有一个细节：
**每月把权重拉回目标**。不做再平衡会怎样？

涨得好的票权重自然变大，组合慢慢变成"单押幸存者"。
极端情况：两年不 rebalance，等权组合可能变成 70% 押在一只票上。

**再平衡的本质是持续的"高抛低吸"** —— 它本身就有收益贡献（rebalance premium），
但在单边牛市里会拖累收益（不断卖出强势股）。这是个 trade-off，没有免费答案。

## 五、实战建议

1. **持仓 5~20 只**：少于 5 只分散无效，多于 20 只研究跟不上
2. **起步用逆波动率或风险平价**，别用均值方差优化（它还要你估计预期收益 ——
   那是所有金融估计里最不可靠的一个）
3. **每月再平衡一次**足够，越频繁成本越高
4. **定期检查风险贡献**：偏离目标太多 = 组合已经漂移，该再平衡了
5. **把"权重集中度"当成风控指标**：单票 > 25% 就该警惕

## 动手练习

1. 把 `min_variance()` 的 `long_only` 改成 False，看哪些票出现负权重，想想它意味着什么
2. 改变 rebalance 频率（None / ME / QE），对比绩效
3. 构造一个"两只票完全同涨同跌"的极端协方差矩阵，看最小方差会给出什么权重
4. 用 2022 单年数据估计协方差，拿到 2023-2024 用 —— 观察优化模型的样本外衰减
5. （挑战）实现"目标波动率"策略：组合年化波动超过 20% 就整体减仓
