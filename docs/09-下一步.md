# 09 · 下一步：从这里到哪里去

> 时间预算 2 小时读完 + 一辈子的实践。

## 一、先恭喜，再泼冷水

恭喜：你已经完成了"数据 → 策略 → 回测 → 评估 → 组合"的完整闭环，
并且亲眼见过回测怎么骗人。**这个闭环比任何理论课都值钱。**

泼冷水：你现在掌握的是"日频股票量化的最小完整技能集"，
离"能实盘赚钱"还有相当距离，离"能做量化工作"差一个数量级的积累。

**但方向是对的：闭环优先，深度其次。** 先有一个能跑通的小系统，
再逐块加深，永远比"先学完所有理论再动手"强。

## 二、从回测到实盘的正确姿势

**绝对不要**：回测跑完 → 充值 → 上实盘。中间隔着三个阶段：

### 阶段 1：纸面交易（至少 3 个月）

每天收盘后跑 `examples/07_daily_monitor.py` 的逻辑：

```
1. 用最新数据重算信号
2. 记录"今天该做什么"（买/卖/持有）
3. 按收盘价模拟记账
4. 每周对比：模拟收益 vs 回测同时段的预期
```

**看什么？偏差。** 回测说该涨的时候实盘走势不同、成交价和收盘价差多少、
信号翻转的频率是否和回测一致。偏差超过阈值就停下来找原因。

### 阶段 2：最小真金（3~6 个月）

- 金额小到"亏光了也不心疼"（比如 1 万）
- 只跑一个策略，不动参数
- **每天写交易日志**：今天为什么买/卖？情绪如何？和系统信号一致吗？

### 阶段 3：逐步加仓

只有前两个阶段的偏差都在预期内，才谈加仓。加仓后策略容量、
滑点都会变化，回测结论需要重新验证。

## 三、技能树：按方向选分支

```
                    ┌─ 机器学习方向：特征工程 → LightGBM/XGBoost → 因子挖掘
                    │
当前位置 ── 深化 ────┼─ 工程方向：向量化回测 → 事件驱动框架 → 实盘系统
（日频股票）        │
                    ├─ 品种方向：ETF/可转债 → 期货 CTA → 期权波动率
                    │
                    └─ 研究方向：风险模型(Barra) → 组合优化 → 资产配置
```

四条路的共同前置（先把这几个补齐）：

1. **统计**：假设检验、bootstrap、多重检验校正（为什么测 100 个因子总有 5 个"显著"）
2. **时间序列**：ARIMA/GARCH 的思想（不一定要会用，要知道它解决什么）
3. **数据工程**：SQL、parquet、增量更新、数据校验管道
4. **读研报**：券商金工报告是最好的免费教材，重点看研究流程不看结论

## 四、值得读的东西（按顺序）

**书：**

1. 《主动投资组合管理》Grinold & Kahn —— 量化的"圣经"，IR = IC × √BR 这个公式值得单独立一章
2. 《量化股票组合管理》Chincarini —— 把第 7 章展开成 500 页
3. 《打开量化投资的黑箱》Narang —— 非技术向，了解行业全貌
4. 《Advances in Financial Machine Learning》López de Prado —— ML 方向必读，重点看"回测过拟合"那几章

**开源项目（读代码学架构）：**

- `qlib`（微软）—— 研究平台架构的范本，数据/因子/模型/回测分层清晰
- `backtrader` / `vnpy` —— 事件驱动回测框架，当你理解了本教程的向量化引擎后再去读，会轻松十倍

**避开的坑：**

- 别一上来就学高频/做市 —— 需要 tick 数据、托管机房，个人玩家没有入场券
- 别迷信"量化课程大礼包" —— 99% 的内容是本教程第 1-4 章的注水版
- 别在策略稳定前碰杠杆

## 五、把学到的变成作品

如果你在准备求职（AI 应用/开发方向），这个仓库可以往两个方向长：

1. **技术叙事**：数据管道（双源容灾 + 三级兜底）、60 行回测引擎、
   可复现实验（快照 + 固定种子 + 参数集中管理）——
   这些是工程能力的证据，面试聊"你怎么保证实验可复现"时全是弹药
2. **算法叙事**：IC 检验、分层回测、样本内外对比、因子衰减分析 ——
   把 examples/04 的"因子全灭"写成一篇诚实的复盘，
   比十篇"年化 30%"的教程更打动懂行的人

**诚实本身就是竞争力。** 这个行业不缺"我有个年化 50% 的策略"的人，
缺"我知道我的回测哪里可能错"的人。

## 六、最后的清单

每天问自己：

- [ ] 我的信号用了未来数据吗？
- [ ] 我的股票池有幸存者偏差吗？
- [ ] 成本算了吗？滑点给了多少？
- [ ] 样本外测过吗？测了几次？（超过 3 次就失效了）
- [ ] 这个结论换个标的/时段还成立吗？
- [ ] 我能把这个策略的逻辑讲给外行听懂吗？

最后一个问题最重要：**讲不清楚的策略，说明你还没理解它，只是在拟合曲线。**
