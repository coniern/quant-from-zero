# 07 · 多因子选股

> 时间预算 10 小时（本章是全书最重的）。对应代码：`src/factors.py` + `examples/04_factor_ic.py`

## 一、问题的升级

前五章解决的是**择时**："现在该不该在场？"

多因子解决的是**选股**："这一堆票里，哪 20 只更可能跑赢？"

两者是正交的维度，可以组合：

```
总仓位 = 择时信号（0~1）
持仓结构 = 多因子打分（谁进组合）
```

机构的主流做法就是"指数增强"：β 靠满仓指数成分，α 靠因子打分微调。

## 二、什么是因子

**因子 = 一个对每只股票每天都能算出来的数值，并且你相信它和未来收益相关。**

| 因子 | 计算 | 逻辑 | 方向 |
|---|---|---|---|
| 动量 | 过去 20 日收益 | 强者恒强 | 越大越好 |
| 反转 | 过去 5 日收益取负 | 短期超涨会回落 | 越大越好 |
| 低波动 | 20 日波动率取负 | 低波股被忽视、更稳 | 越大越好 |
| 乖离率 | (价格-MA20)/MA20 | 偏离均值后回归 | 视情况 |
| 价值 | 1/市净率 | 便宜的公司 | 越大越好 |
| 质量 | ROE、毛利率 | 赚钱能力强的公司 | 越大越好 |

注意"反转 = 动量取负号" —— **同一个数，符号一翻就是另一个因子**。
因子的本质不是公式，是公式背后的那句"我相信什么"。

## 三、IC：因子的体检报告

**IC（Information Coefficient）= 每天所有股票的因子值与未来收益的相关系数。**

```
IC_t = Spearman(因子值_所有股票_t, 未来收益_所有股票_t)
```

**为什么用 Spearman（秩相关）不用 Pearson？**
因为我们只关心"排序对不对"：因子值 1.6 的票是否真的比 1.5 的涨得多。
Spearman 只看排名，对异常值稳健 —— 一只票暴涨 300% 不会扭曲整个相关系数。

实现（`src/factors.py::_corr`，手写，不依赖 scipy）：

```python
a, b = a.rank(), b.rank()          # 各自转成排名
return np.corrcoef(a, b)[0, 1]     # 排名的 Pearson = Spearman
```

### 怎么判断因子死活

| 指标 | 含义 | 及格线 | 良好 |
|---|---|---|---|
| IC 均值 | 方向对不对 | \|IC\| > 0.02 | > 0.05 |
| ICIR = IC均值/IC标准差 | 稳不稳 | > 0.3 | > 0.5 |
| IC > 0 占比 | 多少时间方向正确 | > 55% | > 60% |
| 多空年化 | 纯 alpha 有多大 | > 5% | > 15% |

**ICIR 比 IC 均值更重要。** IC 均值 0.05 但 ICIR 0.1 的因子，
意味着它靠某几个极端日撑着 —— 你不可能只在那几天交易。

### 实测：五个经典因子全灭

`examples/04_factor_ic.py` 在 20 只白马股（2022-2024）上的真实结果：

| 因子 | IC 均值 | ICIR | 多空年化 |
|---|---|---|---|
| 动量20日 | 0.0091 | 0.03 | -17.5% |
| 动量60日 | -0.0033 | -0.01 | -41.5% |
| 反转5日 | -0.0077 | -0.02 | +6.9% |
| 低波动20日 | 0.0046 | 0.02 | -48.0% |
| 乖离率20日 | 0.0070 | 0.02 | -20.9% |

**全灭。** 这是刻意保留的教学结果，三个原因：

1. **20 只大白马没有横截面 alpha** —— 同涨同跌、机构定价充分、没有"烂公司"做对照
2. **样本太短**（3 年）—— 因子有效性本身有周期，3 年只覆盖一个风格周期
3. **幸存者偏差是双重的** —— 见 docs/06 坑二

**学到的真正教训：测出因子全灭是常态。** 学术界 |IC| 0.05 的因子，
发表十年后普遍衰减一半。以后你测出"有效"，第一反应应该是怀疑：
数据泄露？过拟合？样本恰好友好？

## 四、分层回测：让结论可见

IC 是统计量，分层回测是"直接演一遍"：

```
每天把股票按因子值排序，等分 5 组（L1 最低 → L5 最高）
看每组的平均未来收益
```

`src/factors.py::layer_returns()` 的实现细节：

```python
layers = pd.qcut(f.rank(method="first"), 5, labels=[1,2,3,4,5])
row = r.groupby(layers).mean()
```

**为什么按 `rank` 切而不是按值切？** 因子值分布可能极度偏斜
（比如成交量因子，90% 的票都在 1 附近），按值切会把 95% 的票分进同一层。
按排名切保证每层股票数一样多。

**看什么？单调性。** 真正有效的因子，L1→L5 收益应该接近单调。
只有 L5 特别好、中间乱七八糟 → "尾部效应"，你只能吃到最尖那一撮，
实际操作中很难稳定拿到（滑点会把那点超额吃光）。

**多空组合（L5 - L1）** 是因子的"纯 alpha"：同时做多做多做空，
市场涨跌被对冲掉了。分层收益好但多空收益差 → 你赚的只是 beta。

## 五、因子合成：从单因子到打分

多个弱因子可以合成一个强因子。流程：

```python
# 1. 横截面标准化（每天减均值除标准差 —— 注意是按行！）
z = df.sub(df.mean(axis=1), axis=0).div(df.std(axis=1), axis=0)

# 2. 加权求和
score = w1 * z_动量 + w2 * z_反转 + w3 * z_低波
```

三个必须注意的点：

1. **标准化是按天（axis=1），不是按股票**。因子是横截面排名游戏，
   每天的可比性靠当天的标准化保证
2. **合成前先检查因子间相关性**。动量和反转方向相反、相关性 -0.8，
   等权合成 = 白测。相关矩阵 > 0.7 的因子留一个就够
3. **等权起步，别上来就优化权重** —— 权重优化 = 更多的过拟合自由度

## 六、从因子到组合：完整链路

```
每日收盘后：
  1. 算所有股票的因子值 → 合成打分
  2. 选出分数最高的 N 只
  3. 等权（或按分数加权）买入，卖出跌出 TopN 的
  4. 每天评估组合表现
```

把这条链路接上 `run_backtest()` 就是完整的选股策略。
注意选股策略的回测需要处理**调仓日的换手成本**，
以及涨跌停买不进、停牌买不了等约束 —— 这些是工程量的大头。

## 七、下一步的方向（本章只是入门）

按优先级：

1. **扩大股票池**：100~1000 只、含不同行业市值，这是第一杠杆
2. **加入基本面因子**：财务数据（pe/pb/roe）+ 严格按公告日对齐
3. **因子正交化**：对已知因子回归取残差，寻找增量信息
4. **机器学习因子**：LightGBM 预测排序（你之后会看到，特征工程比模型重要）
5. **风险模型**：Barra 风格因子暴露控制，这是机构量化的分水岭
